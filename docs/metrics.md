# Метрики

В каждом прогоне измеряется одна метрика из `targetMetric`. Пайплайн распознаёт перечисленные ниже ключи и учитывает направление улучшения при расчёте cost. Измерение реализовано в обвязке target; текущие Day.js и SVGEdit поддерживают только `operationTimeMs`.

| Ключ | Метрика | Определение | Лучше |
| --- | --- | --- | --- |
| `operationTimeMs` | Время операции, мс | Время завершения заданной операции минус время её начала | Меньше |
| `reactCommits` | Число React-коммитов | Число коммитов выбранного дерева за сценарий; один коммит учитывается один раз | Меньше |
| `reactRenderTimeMs` | Суммарное время React-рендеринга, мс | Сумма `actualDuration` одного выбранного React Profiler за сценарий, без сложения вложенных профайлеров | Меньше |
| `rafFps` | Средний FPS по `requestAnimationFrame`, кадров/с | Число интервалов между последовательными вызовами за сценарий / их суммарная длительность в секундах | Больше |

Для каждого сценария сохраняются исходная серия замеров, медиана, p95, минимум, максимум и разброс `max − min`. p95 вычисляется методом ближайшего ранга: элемент с номером `ceil(0,95 × N)` в отсортированной серии, где нумерация начинается с 1.

Источники измерений: [React Profiler](https://react.dev/reference/react/Profiler), [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame).
