# Day.js: работа с датами в веб-интерфейсе

[Исходник](https://github.com/iamkun/dayjs/tree/436bde0bcded312781cbe45dc2b0ef079a36d8e3): коммит `436bde0bcded312781cbe45dc2b0ef079a36d8e3`. Обвязка подключает production-сборку ядра, плагинов и локалей именно переданного слепка; пути проверяются через esbuild metafile.

| Сценарий | Объём | Операция |

Данные в `fixtures.ts` детерминированы и охватывают 2023–2024 годы. Часы браузера фиксированы на `2024-06-15T12:00:00Z`, в том числе для разрешения неоднозначного времени при DST. Фиксируется только `Date`; `performance.now()` остаётся нативным. COOP/COEP включают изолированный контекст с точным таймером; обвязка проверяет его перед замером.

Метрика `operationTimeMs` измеряет только выполнение сценария — вызов `operation(scenario)` над всем набором данных, включая обход данных, вызовы Day.js и формирование результата. Генерация данных, загрузка ядра, подключение плагинов и локалей выполняются до таймера; операций прогрева нет. Проверки результата выполняются после таймера. Каждый повтор — один вызов в новом Chromium context: UTC, en-US, 1280×900, scale 1, отключённые HTTP-кэш, service workers и внешняя сеть.

Для каждого сценария `expected.json` хранит число строк и SHA-256 полного упорядоченного результата. Эталоны получены на отдельной копии исходного коммита; четыре сценария дополнительно сверяются с независимым расчётом через JavaScript Date. `prepare` не обновляет эталоны. Для намеренного обновления исходной версии используется `freeze.ts`.

## Проверка

```sh
caffeinate -i npm --prefix targets/dayjs/harness ci --ignore-scripts
caffeinate -i npm --prefix targets/dayjs/harness run check
```

Во время прогона `prepare` устанавливает зависимости по lock-файлам и запускает upstream build (включая size-limit). `test` запускает lint и полный `npm test` с матрицей часовых поясов и 100% порогом покрытия строк. Все `test/*spec.js` выполняются без изменений через upstream Jasmine в Chromium. Облачная матрица старых браузеров Sauce Labs не воспроизводится.

Для старого Webpack из upstream size-limit обвязка задаёт `--openssl-legacy-provider`; зависимости не обновляются. Копия исходного lock-файла хранится в `library-package-lock.json` и сверяется перед подготовкой. Измерения характеризуют фиксированные пакетные операции в Chromium; загрузка страницы и межбраузерная совместимость в метрику не входят.
