# Сценарии SVGEdit

Фиксированные документы: чередующиеся прямоугольники и круги размером 12×12, сетка из 40 столбцов с шагом 20, две заливки. ID, координаты и размеры детерминированы; генератор — `fixtures.ts`.

Все команды выполняются в настоящем редакторе. Измеряется только синхронный вызов API и его обработчики; подготовка и проверки вне интервала.

| Сценарий         | Начальное состояние             | Измеряемая команда                     | Проверка результата                                           |
| ---------------- | ------------------------------- | -------------------------------------- | ------------------------------------------------------------- |
| `select-500`     | 500 фигур без выделения         | Выделить слой                          | 500 правильных ID, геометрия и история не изменились          |
| `move-500`       | 500 выделенных фигур            | Сдвинуть на (20, 10)                   | Каждая координата, размеры, заливка, undo                     |
| `duplicate-500`  | 500 выделенных фигур            | Дублировать со сдвигом (20, 10)        | 1000 фигур, уникальные ID, геометрия и заливка копий, undo    |
| `group-2000`     | 2000 выделенных фигур           | Сгруппировать                          | Одна выделенная группа, все фигуры внутри, геометрия, undo    |
| `ungroup-500`    | Группа из 500 фигур выделена    | Разгруппировать                        | 500 выделенных фигур непосредственно в слое, геометрия, undo  |
| `align-left-500` | 500 выделенных фигур            | Выровнять слева относительно выделения | Все x = 20, прежние y и размеры, undo                         |
| `fill-5000`      | 5000 выделенных фигур           | Установить fill = `#4060a0`            | Заливка каждой фигуры, неизменная геометрия, запись в истории |
| `delete-5000`    | 5000 выделенных фигур           | Удалить                                | Нет фигур и выделения, запись в истории                       |
| `undo-move-500`  | 500 фигур после сдвига (20, 10) | Undo                                   | Исходные координаты и свойства, размеры стеков истории        |
| `redo-move-500`  | Сдвиг 500 фигур отменён         | Redo                                   | Сдвинутые координаты, свойства и стеки истории                |

Во всех сценариях проверяются количество фигур, уникальность ID, исходная геометрия и заливка. Для изменяющих документ команд проверяется изменение истории. Проверки не полагаются на время операции: пустая команда не считается ускорением.

Крупные документы для группировки, заливки и удаления увеличивают длительность коротких операций. Они не задают отдельные веса: пайплайн усредняет нормализованные медианы всех десяти сценариев одинаково.
